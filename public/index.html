01 — features

Thin, predictable, drop-in.

Compat
OpenAI wire format
Same request shape, same response shape, same SSE chunks. Point the official openai SDK at this gateway's base URL and it just works.
Routing
Namespaced model IDs
Models are addressed as provider/native-id — e.g. openrouter/anthropic/claude-sonnet-4.5. No global ID collisions, no surprises.
Stream
First-class SSE
Token-by-token streaming for every provider, normalized to OpenAI delta chunks with [DONE] sentinels. Reasoning effort passthrough included.
Local
CLI providers as HTTP
Wraps claude, codex, and opencode CLIs behind the same OpenAI shape. Local models become a normal API call.
Images
Image generation
A /v1/images/generations route mirrors the OpenAI image API, with generated assets served from /generated/*.
Docs
Live OpenAPI
Schemas are generated from the route definitions, not hand-written. Browse /openapi for the always-current contract.
Runtime
Bun + Elysia
Single binary dev loop, sub-millisecond router, zero-config TypeScript. bun run dev and you're online.
02 — quickstart

Talk to it in ten seconds.

# streamed chat completion via the gateway
curl "http://127.0.0.1:3000/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openrouter/anthropic/claude-sonnet-4.5",
    "stream": true,
    "messages": [
      { "role": "user", "content": "Write a haiku about Bun." }
    ]
  }'
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "http://127.0.0.1:3000/v1",
  apiKey: "unused", // gateway forwards your provider keys
});

const stream = await client.chat.completions.create({
  model: "claude-code/claude-sonnet-4-5",
  stream: true,
  messages: [{ role: "user", content: "hello" }],
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:3000/v1",
    api_key="unused",
)

stream = client.chat.completions.create(
    model="codex/gpt-5-codex",
    stream=True,
    messages=[{"role": "user", "content": "hello"}],
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
